## 代码与可移植性修改

1. 将生产代码的中文注释、docstring、notebook 说明及中文提示转换为英文。检查结果：生产代码和 notebook 中无中文说明残留、无个人绝对路径。保留函数接口及原有科学算法。
2. 清空所有 notebook outputs/execution_count 和运行元数据，避免输出图、日志、路径及个人结果随 notebook 进入 Git。更新 step 5 中过时的“电离态等权”描述为逐线等权，并修正误差说明。
3. config.resolve_ispec_dir 使用 ISPEC_EW_ROOT 或 Code 上级作为工作区。原始源代码中的 ISPEC_DIR 行为不变；只有发布副本切换，避免新仓库误用原 iSpec 的数据/输出目录。
4. inlist 删除用户绝对输入路径；默认保留 HD73350，文献比较设为 None，避免没有公开文献表时默认报错。目标例谱依据其专用 metadata filename 识别为 nm、已归一化 FITS。其他目标仍使用通用路径或显式覆盖。
5. 太阳 notebook 默认只配置授权的 R45500 示例；跳过已完成的预处理，首次运行创建太阳输出目录。移除旧版本一次性 HFS 库修复单元，当前正式太阳流程本身已完成同步。
6. HFS 删除个人 MOOG 安装位置兜底，保留 MOOGSILENT_PATH/PATH 配置。保留诊断日志功能，但移除过期 agent session 标识和 region 标记。
7. VALD 文件名统一为 atomic_lines.tsv；没有复制近 1 GB 的用户 VALD 库。已有交叉匹配例线表可直接运行；重建线表时另行提供合法 VALD 数据。
8. 补入外部运行环境链接脚本、只读前置检查脚本、环境规格、清洁发布脚本和英/中文文档。

没有更改逐线均值、q2 参数求解、iSpec 元素丰度、HFS 选择、O 三重线 NLTE、局部归一化算法或当前人工 QA 状态机。

## 外部依赖及资源

运行资源特定小文件：当前 Melendez2014 线表（原始和 iSpec 格式）、HFS 模板、连续谱窗口、Tc 表。大型模型/线库、iSpec 引擎、MOOG、q2 和 linemake 均不复制进发布内容，安装脚本只建立本地忽略链接。iSpec 已存在的 __init__/MOOG 解析兼容变更以补丁记录，不自动修改用户外部引擎；其上游许可单独随补丁保存。

参考环境版本与 q2 文件哈希见 runtime_versions.json。原环境没有可用于锁定的 q2 分发版本号，因此记录文件校验值而不编造版本。环境规格不是声称已在全新机器完成从零安装验证。

## 安全清理和 Git

目标仓库原 Code/input/output/README 及旧系统文件在替换前移入 .migration_backup 下的时间戳目录；备份被 Git 忽略。删除的是发布工作树中的旧入口和旧资源，实际旧文件有备份，源 iSpec 完全保留。

旧 Git 历史保留，不重写提交、不强推、不自动发布。旧历史已经含约 1 GB 的对象，仅忽略 input/output 不会清除历史。dist/iSpec_EWAbund_20261022.zip 按 release_manifest.json 白名单生成，既不含 .git，也不含备份、运行链接和个人输出。需要无旧数据的新公开仓库时，从该包解压后 git init；不要复制原 .git。
